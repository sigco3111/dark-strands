탐험 안내

SHIFT+?로 닫기
⚔ 이동
걷기와 달리기
WASD로 이동합니다. SHIFT를 누르면 두 배 속도로 달립니다.
점프와 이단 점프
SPACE로 점프합니다. 공중에서 다시 누르면 이단 점프합니다. 발판에서 떨어진 직후에도 잠깐 점프할 수 있습니다.
확대
마우스 오른쪽 버튼을 누르면 3배 확대됩니다. 멀리 있는 지형과 물체를 살펴보세요.
💬 상호작용
상호작용
문, 병사, 꽃, 돌, 횃불, 침대 가까이에서 E를 누릅니다. 월드에 뜨는 [E] 안내를 확인하세요.
던지기와 배치
돌을 선택하고 왼쪽 클릭하면 던집니다. E를 누르면 배치 모드로 전환됩니다. 초록색 미리보기를 보고 클릭하여 놓으세요.
꽃과 횃불
E로 꽃과 횃불을 줍습니다. 선택 후 왼쪽 클릭으로 배치합니다. 꽃은 지면에, 횃불은 벽이나 바닥에 놓습니다.
🎯 카메라와 HUD
카메라
V로 1인칭과 어깨 너머 3인칭 시점을 전환합니다.
빠른 도구창
1~5로 슬롯을 선택합니다. ALT를 누르면 가상 커서가 나타납니다. 아이템을 드래그하여 슬롯 순서를 바꿉니다.
일시 정지
TAB은 커서를 잠근 채 일시 정지합니다. ESC는 게임을 계속하며 커서를 해제합니다. 클릭하면 다시 잠급니다.
빠르게 진행
Q를 누르면 월드가 3배 속도로 진행됩니다. 시간, 이동, 애니메이션이 모두 빨라집니다.
⚔ 터치 조작
이동
화면 왼쪽을 터치하고 드래그하세요. 터치한 곳에 가상 조이스틱이 나타납니다.
둘러보기
화면 오른쪽을 쓸어 카메라를 돌립니다. 왼손으로 이동하고 오른손으로 시점을 조절하세요.
점프
오른쪽 아래 점프 버튼을 누릅니다. 공중에서 다시 누르면 이단 점프합니다.
상호작용
상호작용할 물체 가까이에서 화면 오른쪽을 1초 동안 움직이지 않고 누릅니다. 원형 진행 표시가 채워지면 실행됩니다.
아이템 사용
사용 버튼을 눌러 돌 던지기, 배치 모드, 횃불과 꽃 배치를 실행합니다.
도구창과 카메라
도구창 슬롯을 눌러 선택합니다. 시점 버튼으로 1인칭과 3인칭을 전환합니다.
🏠 탐험
건물
돌 건물에는 문, 깨지는 창문, 가구가 있습니다. 일부 건물은 계단과 탁자, 의자, 침대가 있는 2층입니다.
지붕
올라갈 길을 찾아 지붕에 올라보세요. 경사진 지붕은 미끄러워 돌이 굴러떨어집니다. 평평한 지붕은 좋은 전망대입니다.
지형과 물
완만한 언덕이 이어집니다. 물에 들어가면 수중 화면이 나타나며 이동 속도가 40%로 줄고 중력이 가벼워집니다.
설원 환경
메인 메뉴에서 설원을 선택합니다. 물이 걸을 수 있는 얼음으로 변하고 나무도 겨울 모습이 됩니다.
💥 돌과 물리
던지기
돌을 선택하고 왼쪽 클릭하여 던집니다. 돌은 벽과 지형에서 튕기며 경사진 지붕에서 굴러떨어집니다.
배치 모드
돌을 선택하고 E로 배치 모드를 전환합니다. 초록 미리보기를 보고 클릭하면 던지지 않고 조심스럽게 놓습니다.
돌 밀어내기
던진 돌로 바닥의 작은 돌을 맞히면 충격이 전달됩니다. 각도를 바꾸며 연쇄 반응을 시험해보세요.
유리창 깨기
돌을 유리창에 던지면 창이 깨집니다. 유리 조각이 흩어지고 깨진 창으로 투사체가 통과합니다.
💬 생물과 NPC
병사
초록빛 병사들이 주변을 돌아다닙니다. 가까이 다가가 지혜롭거나 엉뚱한 이야기를 들어보세요.
여우
겁 많은 여우들이 황야를 돌아다닙니다. 가까이 다가가면 도망갑니다. 조용히 접근해보세요.
☀ 낮과 밤
시간 주기
메인 메뉴에서 낮과 밤 주기를 켭니다. 해가 움직이고 해 질 무렵 횃불이 켜지며 밤에는 별이 나타납니다.
잠자기
건물 안의 침대와 상호작용하여 아침까지 잘 수 있습니다. 낮과 밤 주기가 켜져 있어야 합니다.
🎯 HUD
미니맵
오른쪽 위 미니맵에 내 위치는 노란 점, 건물은 갈색, 꽃은 청록색으로 표시됩니다.
